# 243-4J5 — Projet final Hydro-Limoilou (semaines 12 à 15)

Point de départ du projet final du cours 243-4J5-LI – Objets connectés, Cégep Limoilou.

| Dossier | Utilisation |
|---------|-------------|
| `docs/` | Contrat du serveur central et vérifications avant chaque checkpoint |
| `firmware/` | Code du nœud de votre site |
| `interface/` | Interface tactile du Raspberry Pi |
| `kicad/` | Shield, Gerbers et BOM |

## Démarrer

1. Cliquez sur **Fork** pour créer votre copie. Un fork d'un dépôt public reste public.
2. Clonez votre fork sur le Raspberry Pi et poussez votre travail à chaque checkpoint.

**Ne publiez jamais vos identifiants.** Le mot de passe de votre broker reste dans un fichier ignoré par Git.
